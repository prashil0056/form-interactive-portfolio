# FORM — Interactive portfolio starter

A self-contained creative portfolio inspired by the visual direction in your reference video. It uses HTML, CSS and JavaScript (no build tools required).

## Run it
1. Unzip the folder.
2. Open `index.html` in Chrome, Safari, or Firefox.
3. For a better coding workflow, open the folder in VS Code and use the Live Server extension.

## Interactions included
- Smooth anchor navigation
- Scroll reveal animations using IntersectionObserver
- Custom cursor on desktop
- Hovering project artwork and arrow movement
- Click/keyboard-accessible project case-study modals
- Escape key and backdrop click to close the modal
- Responsive layout and reduced-motion support

## Customize it
- Edit copy and project names directly in `index.html`.
- Change colors in the `:root` CSS variables near the top.
- Replace the CSS poster illustrations with your own images later.
- Edit the `projectData` object in the script to update each project modal.

This is an original prototype inspired by the broad visual language of the video, not a pixel-perfect copy of the unidentified original site. The project artwork is made with CSS shapes, so it loads without external image assets. Google Fonts load from the internet; system fallbacks are included.
